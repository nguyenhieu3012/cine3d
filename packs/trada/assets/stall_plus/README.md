# Textures of the stall `plus` set (`packs/trada/stall_plus.js`)

Six 1K JPG maps copied from the studio kit (`~/studio-assets/polyhaven/textures/`) so the engine does not depend on a path outside this folder.
All are **Poly Haven** assets, licence **CC0 1.0** (public domain, https://polyhaven.com/license). Only the normal map (OpenGL convention) and the roughness map are used;
the colours of the set stay the channel's own.

| file here | Poly Haven asset | author | used on |
|---|---|---|---|
| `wall_nor.jpg`, `wall_rough.jpg` | `rough_concrete` | Dimitrios Savva | shop wall plaster, dado (1.1 m per repeat), far side walls |
| `floor_nor.jpg`, `floor_rough.jpg` | `concrete_floor_worn_001` | Dimitrios Savva, Rico Cilliers | pavement tiles (1.4 m per repeat) |
| `road_nor.jpg`, `road_rough.jpg` | `asphalt_02` | Rob Tuytel | the wet side street (1.6 m per repeat) |
