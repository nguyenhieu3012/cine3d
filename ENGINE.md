# cine3d: one 3-D engine for every channel (from 13/11/2026)

Run everything through the shortcut `~/cine3d` (no spaces in the path). Real code lives in the vault at `Tools/cine3d/`.
`node_modules` is a link to `~/tdvai/node_modules` (three 0.170, playwright).

## Why it exists
The old "3-D" engines (`~/tdvai/shared`, `~/goat-beef-test/v2`) draw flat 2-D characters on top of a 3-D background, so characters get no real light,
no real shadow, cannot turn their heads and the camera cannot go round them. They are also two hand-copied forks.
cine3d has ONE core for all channels and real 3-D characters:
- characters are meshes lit by the scene lights, with shadow maps, a head that turns, eyes that look at someone, a drawn face mapped on the head;
- a real lens: focal length, distance and height solved from where the heads are; depth of field from the real depth buffer;
- picture chain: HDR scene (MSAA) -> depth of field -> HDR bloom -> AgX tone map -> grade (contrast, split tone, vignette, grain);
- an episode is **plain data** (about 40 lines), not a 50 KB program;
- render speed measured 13/11 on the M4: about 21 frames per second (12 s of 1080 x 1920 @ 30 in 22 s), roughly twice as fast as the old v3 look.

## The look (settled with the owner, 13/11)
Warm, bright and friendly first, cinematic second: the old 2-D characters felt "gần gũi" and the first, darker pass of this engine did not.
- Every character gets an **ink outline** (`inkOutline` in `core/rig.js`, switched on per pack in `packs/index.js`: `outline: { color, t }`; `ep.outline: false` or the page flag `&ink=0` turns it off; mark a mesh `userData.noOutline = true` to leave it out).
- Sets use the channel's familiar colours (Trà đá: orange wall, green dado, red tiles, bunting) at saturation about 1.3, but **the background stays clearly darker than the characters** (dim wall, low fill, little bloom): a frame that is bright all over washes the characters out (the owner, 13/11).
- **Known faces are not redesigned.** Bíp's face is measured from the old frames (pillow visor, two thick flat bars close together, a short dash mouth, cheeks far out); the flat bars are his judging stare. Making a character "cuter" must never change the features people know.
- Faces are big and soft (large eyes, clear blush); singles are shot nearly frontal (`ms` 12 degrees, `cu` 9) with only light background blur.
When tuning further, keep this direction; do not drift back to dark and cool.

## An episode file (`export default { ... }`)
```js
{
  pack: 'trada', set: 'stall', fps: 30, dur: 12.15, cast: ['teo', 'bip'],
  lipsFile: 'demo/trada_ep55_lips.json',          // made by tools/lips.cjs from the voice stems
  castOpts: { leo: { jersey: 'red7' } },          // optional: options passed to a character's builder
  seats: { ... },                                 // optional: override / add seats ({ name: { pos: [x, y, z], yaw } })
  captions: { y: 1385, size: 76, max: 14 },       // optional; GOAT Beef uses { y: 1421, accent: '#ffe45a' } (accent = colour of stressed words; default = the speaker's colour)
  shots: [ { t0: 0, t1: 1.05, cam: 'cu_teo', move: 'push', amt: 1.4, punchAt: 0.8, eyes: { teo: 'cam' } }, ... ],
  lines: [ { who: 'teo', t0: 0.10, t1: 1.79, text: 'Tin nào tao cũng không mở.', emo: 'sleepy', pose: 'cross' }, ... ],
  acts:  [ { t: 6.2, who: 'teo', emo: 'smug', pose: 'chin' }, { t: 6.3, who: 'teo', look: 'cam', d: 2.1 }, { t: 7.0, who: 'teo', nod: 'yes' } ],
  overlays: [ { kind: 'hook', t0: 0, t1: 2.9, text: ['NHỊN 15 NGÀY:', 'ĐỌC HAY KHÔNG?'], y: 262 },
              { kind: 'bubble', t0: 9, t1: 11.5, from: 'Crush', text: 'Ngủ chưa?', x: 96, y: 300 } ],
}
```
`mblur: 4` on the episode (or page flag `&mb=4`) = motion blur from 4 sub-frames (render time x4; use it for action, not for talk).
`hits: [{ t, frames: 3 }]` on the episode = hit-stop: the picture freezes 2-3 frames on an impact, the sound runs on.
All times are absolute seconds. Shots must tile the whole duration (each `t0` = the previous `t1`). Cuts are hard cuts.

### Shots
`cam` = a token: `wide` · `two` · `ms_<who>` · `cu_<who>` · `ecu_<who>` · `ots_<who>` (who = the one in focus), each optionally ending in `_lo`
(camera looks up: the winner, bravado) or `_hi` (looks down: the loser, shame). The engine keeps the 180 degree rule by construction.
| token | lens | head height in frame | use |
|---|---|---|---|
| `wide` | 27 mm | small | the place, the result |
| `all` | 35 mm | fits everyone | three or more characters in one frame (the stall lady behind the two, a customer) |
| `two` | 42 mm | 12.5 % | both of them: setups, shared reactions |
| `ms_` | 58 mm | 20 % | the default for a spoken line |
| `cu_` | 85 mm | 37 % | the punch line, the reaction |
| `ecu_` | 105 mm | 50 % | ONE beat: the face breaks |
| `ots_` | 58 mm, from far round the partner's side | 19 % | a line said TO the partner; the partner's blurred shoulder is in frame |

Three or more people: `frame: ['teo', 'bip', 'ba']` on a `two` / `wide` / `all` shot frames exactly those; `partner: 'ba'` on a single (`ms_`, `cu_`, `ots_`) says who the subject is talking to; `partners: { ba: 'teo', teo: 'bip' }` on the episode sets everybody's default partner (who they look at, which side the camera takes).
Other shot fields: `move`: `push` (default) / `pull` / `orbit` / `crane` / `drift` / `none`; `amt` (strength, 1 = normal);
`punchAt: t` or `[t, ...]` (8 % push on a stressed word, then holds); `eyes: { teo: 'cam' }` (where a character looks during this shot);
`dof` (blur strength, 0 = everything sharp); `focusOn: 'bip'`; `shake` (0 = locked off); `dutch` (degrees); `v: 1` (the mirrored variant of `two` / `wide`);
`hold: true` (a deliberate shot longer than 3 s); `rig: { f, head, az, el, eye }` to override the numbers of the token.

### Lines and acts
A line gives the mouth (from the voice envelope), the caption, and optionally `emo` and `pose` that start with it.
`acts` change things at any moment: `emo`, `pose`, `look` (`'cam'`, `'partner'`, a character name, `'down'`, `'up'`, `'away'`; `d` = for how long),
`nod` (`'yes'`, `'no'`, `'jolt'`). Without a `look`, the speaker looks at the partner and the listener at the speaker, both "cheated" halfway to the camera
(`ep.cheat`, default 0.5) so faces stay readable. Emotions blend over 0.2 s, poses over 0.34 s with one small overshoot, heads turn over 0.3 s.
A line whose `who` is not in the cast (a voice off screen) only makes a caption.

Supporting cast of Trà đá (`packs/trada/people.js`): `ba` (Bà chủ quán, stands), `me` (Mẹ, stands), `khach` (anh khách, seated), all built by `makePerson(opts)` (skin, hair, clothes, pattern, glasses, age, stand): a new person is one call. They use Tèo's face names, plus the poses `hips wave give scold`.
Faces, Trà đá: Tèo `neutral happy smug shock worry sad cry angry think deadpan sleepy`; Bíp `neutral` (flat bars = the judging stare, his default) `judge` (narrowed) `smug` (sly, side glance) `side` (side-eye) `deadpan happy shock worry sad angry think love scan`.
Poses (both): `rest table point pointL me raise cheer facepalm chin shrug cross phone cup head beg`.
GOAT Beef (Ron, Leo): faces `neutral happy smug shock worry sad cry angry think deadpan laugh sarcastic unimpressed`; poses as above plus `siu clap`. `castOpts: { leo: { jersey: 'red7', cup: 'mate' } }` = Leo in Ron's shirt, holding a mate gourd in the `cup` pose.

### Overlays
`hook` (plate, 1-2 lines, last line in the accent colour), `chip` (small label), `bubble` (phone message: `from`, `text`, `x`, `y`), `end` (end card: `text`, `sub`).
Every overlay kind the engine has (`core/overlay.js`; the ones marked ZB are in `core/overlay_zb.js`). All take `t0`, `t1`; drawn in list order, captions last. Calls, bank and receipt-like screens exist: `call`, `calling`, `notify`, `balance`, `transfer`, `qr`.
- `hook`: title plate over the first seconds; `text: [line1, line2]`, `y`, `size`, `color`. Ex: `{ kind: 'hook', t0: 0, t1: 2.95, text: ['CON NHẮN MẸ', 'DÀI THẾ?'], y: 236 }` (t60).
- `chip`: small label (series tag, place, time); `text`, `x`, `y`, `color`. No episode uses it yet (code only).
- `bubble`: floating phone message; `from`, `text`, `x`, `y`, `size`, `color`. Ex: `{ kind: 'bubble', t0: 9.0, t1: 11.5, from: 'Crush', text: 'Ngủ chưa?', x: 96, y: 300, color: '#ff6f9a' }` (`demo/trada_phone.js`).
- `end`: end card; `text`, `sub`, `color`. Ex: `{ kind: 'end', t0: 7.4, t1: 9, text: 'Mẹ thật hay giả?', sub: 'THEO DÕI · 0Đ' }` (`demo/trada_ep55.js`).
- `phone`: phone with a chat thread over the blurred picture; `name`, `sub`, `avatar`, `accent`, `logo: 'gpt'`, `msgs: [{ t, from: 'them' | 'me', text }]`, `typing: [{ t0, t1, from }]`; `big: true` = one large message card (ZB `msgcard`). Every `msgs` entry is a message to read: visible from its `t` to the overlay's end, so it needs `1.0 + characters / 12` s and at most 60 characters (qa `read_time`, `read_long`). Ex: `{ kind: 'phone', name: 'Chíp', sub: 'ChatGPT', logo: 'gpt', big: true, accent: '#10a37f', msgs: [...] }` (ngay12, p9).
- `score`: scoreboard; `left`, `right`, `a`, `b`, `tick: 'a'|'b'`, `tickAt`, `banner`, `y`. Ex: `{ kind: 'score', left: 'RONALDO', right: 'MESSI', a: 5, b: 4, tick: 'a', banner: 'RONALDO WINS BY ONE', y: 225 }` (gb04).
- `backdrop`: blur + dim the 3-D picture; `blur`, `dim`. Ex: `{ kind: 'backdrop', t0: EC0, t1: EC1, blur: 16, dim: 0.55 }` (t60).
- `draw`: any 2-D insert; `fn(ctx, t, { ep, cast, k })`, `fade`. Ex: the browser-tab strip `tabs` in ngay12, the chat thread, call bar and bank card in t60. Old Trà đá 2-D helpers: `legacy_trada/teo.js` (`T.chatScreen`, `T.phoneFrame`, `T.receiptStrip`). Declare what it shows: `reads: [{ text, t0, t1 }]` (one entry per text the viewer must read, with its real visible window) or `noText: true`; neither = qa `draw_undeclared` FAIL. A message needs `1.0 + characters / 12` s on screen and at most 60 characters (`read_time`, `read_long`).
- `thought`: thought cloud over `who`'s head (or `ax, ay`); words appear `r0`..`r1`; `text`, `pop: false` continues the last cloud, `maxW`, `size`. Ex: `{ kind: 'thought', who: 'ba', text: 'Đá hôm qua. Pha thêm nước.', r0, r1 }` (ngay12).
- `call`: incoming-call card with sound bars that follow `who`'s lines; `name`, `who`, `answer` (time it is answered), `y`. Ex: `{ kind: 'call', name: 'MẸ', who: 'me', answer: 1e9, y: 176 }` (t60).
- `notify`: bank notification card; `app`, `text`, `icon`, `y`. Ex: `{ kind: 'notify', app: 'NGÂN HÀNG', text: '+500.000đ', y: 176 }` (ngay12; 1.8 s wanted by QA).
- `unlock`: locked teaser plate that swaps text; `a`, `b`, `swapAt`, `follow`, `y`. Ex: `b: 'NGÀY 13: NHÌN THẤU ???'` (ngay12).
- `pill`: follow line at the tail; `text`, `size`, `color`, `y`. Ex: `{ kind: 'pill', text: 'THEO DÕI · MẸ BẮT TIẾP', y: 300 }` (t60).
- `chest`: round window on `who`'s chest with a tiny drawn room; `room(ctx, t, {r,u,k})`, `r`, `rim`, `at`, `slam` (see Ngày 13 below). Ex: `{ kind: 'chest', who: 'ba', room: roomBa(), r: 240 }` (ngay13).
- ZB `calling`: full call screen on a device inset, pulsing accept ring; `name`, `sub`. Ex: `{ kind: 'calling', name: 'MẸ', sub: 'Đang gọi…' }` (camon2).
- ZB `balance`: red alarm screen; `amount`, `label`, `balance: false` hides the SỐ DƯ line. Ex: `{ kind: 'balance', label: 'KHÔNG ĐỦ', amount: '2.000đ' }` (camon2).
- ZB `transfer`: transfer screen, real or AI-fake; `amount`, `to`, `fake` 0..1 or `fakeAt`. Ex: `{ kind: 'transfer', amount: '1.000.000đ', to: 'Chủ nợ' }` (camon2).
- ZB `counter`: follower counter inset; `keys`, `roll`, `names` (see "Follower counter" below). Ex: `{ kind: 'counter', keys: KEYS, roll: ROLL }` (camon2).
- ZB `qr`: QR standee (made up, cannot scan); `label`, `size`, `sway`, `y`. Ex: `{ kind: 'qr', t0: 18.0, t1: 19.2 }` (`demo/zb_overlay_look.js`).
- ZB `blank`: dark empty device screen; same inset options. Ex: `{ kind: 'blank', t0: 16.8, t1: 18.0 }` (`demo/zb_overlay_look.js`).
- ZB `iris`: black screen with a soft circle (wake-up, closing); `r: [[t, px], ...]`, `who`, `side`, `breathe`, `inner`. Ex: wake-up `{ kind: 'iris', who: 'teo', side: -1, r: [[0, 0], [0.95, 60], [3.2, 1500]], breathe: 6 }` (zombie episode `zb*`).
- ZB `freeze_rewind`: grayscale freeze with text; `text`, `drain`. Ex: `{ kind: 'freeze_rewind', text: '24 GIỜ TRƯỚC' }` (zb).
- ZB `title`: black title card; `text`, `style: 'end'`, `size`, `y`, `fade`. Ex: `{ kind: 'title', text: 'TO BE CONTINUED' }` (zb).
- ZB `white_flash`: `peak`, `hold`, `max`, `color`. Ex: `{ kind: 'white_flash', t0: 17.7, t1: 18.45, peak: 17.94, max: 0.5 }` (zb).
- ZB `cold`: cold blue grade; `in`, `out`, `amount`, `tint`, `dark`. Ex: `{ kind: 'cold', in: 1.8, out: 0.01, amount: 0.2, tint: '#1f4dff', dark: 0.0 }` (zb).
Inset kinds (`calling`, `balance`, `transfer`, `blank`, `counter`) also take `w`, `h`, `y`, `tilt`, `backdrop: false`.
Captions come from the lines by themselves: chunks of at most 3 words / 14 characters, one at a time, words in CAPITALS or with digits take the speaker's colour.
Trà đá caption centre y 1385 (band 1260-1450); GOAT Beef y 1421.

## Commands (in `~/cine3d`)
| | |
|---|---|
| preview in a browser | serve the folder (any static server) and open `index.html?ep=demo/trada_ep55.js` (space = play, arrows = step) |
| stills | `node tools/render.cjs stills <ep.js> <outDir> 1,3.5,7 [--raw]` (`--raw` = no text) |
| video | `node tools/render.cjs mp4 <ep.js> <out.mp4> [--audio mix.wav] [--from s --to s] [--fps 30\|60] [--crf 14]` |
| mouths from the voice | `node tools/lips.cjs <ep.js> --stem teo=vo_teo.wav --stem bip=vo_bip.wav --out <ep>_lips.json` |
| machine QA | `node tools/qa.cjs <ep.js>` must print `ALL PASS` before anyone watches |
| old vs new | `node tools/sbs.cjs old.mp4 new.mp4 out.mp4 "left label" "right label" [seconds]` |
Page flags: `&dof=0.5` (scale all blur), `&mb=4` (motion blur), `&ss=2` (supersample), `&tone=agx|aces|neutral`.

`tools/qa.cjs` checks: at least 3 framings in the first 3 s; no shot over 3 s without `hold`; never the same framing twice in a row; the subject's head inside
the frame with headroom; eye line 28-44 % from the top; mouth above the caption band; the subject's face neither dark nor clipped; caption words fit;
every on-screen line has a voice envelope (warning); the speaker is on screen during a single shot (warning); no page errors.

## Adding things
- **A set:** a function `(scene, opts) => ({ group, light, seats: { name: { pos, yaw } }, look, update(t) })` in `packs/<channel>/`, registered in `packs/index.js`.
  Put the busy things above or beside the heads, keep the patch straight behind the heads calm, give one side real depth, light it with a few practicals.
- **A character:** a function returning `{ name, root, body, head, R, headY, eyeUp, faces, poses, color, apply(pose, t), headWorld() }` (copy `makeTeo`).
- **A light mood:** one line in `lightRig` (`core/stage.js`), or retune per set with `tune(lights)` / per episode with `look: { exposure, bloom, grade }`.
- Everything must stay a pure function of time: no state carried between frames (two render workers must give the same picture).

## Extending the engine without breaking it (read before touching `core/` or `packs/`)
Most new episodes need something the engine cannot do yet (Ngày 12 needed thought clouds, an aura, a call card, table props). This is how it was added in one afternoon without breaking what the owner had approved.
**Where a new thing goes**
| It is | Put it in | Example |
|---|---|---|
| Useful to both channels, no character knowledge | `core/` | free camera, `fx` ramps, `thought` / `call` / `notify` overlays |
| About one character or one set | `packs/<channel>/` | Tèo's aura and gold eyes, the day card and tissue box of the stall (`setOpts`) |
| A one-off drawing for one episode | the episode file, `{ kind: 'draw', fn }` overlay | the strip of 40 browser tabs in `ngay12.js` |
**The patterns to reuse (do not invent a new mechanism when one fits)**
- A value that changes over time → an `fx` number on an act (`{ t, who, fx: { name: 1 }, d }`); the character's `apply(p, t)` or the set's `update(t, fx)` reads `p.name` / `fx.name`.
- A new face → a new entry in the face table, numbers only (they are blended number by number). A new pose → hand targets `l`, `r`; any extra numeric key is passed through to `apply`.
- Text or a card → a new overlay function in `core/overlay.js` with the signature `(ctx, o, t, ep, cast, camera)`, registered in `drawOverlays`; fit text with `fitText`, keep inside `SAFE`.
- A prop that matters → a mesh in the set behind a `setOpts` switch, plus a `free` shot that looks at it.
**Laws (every one of them was broken once today and showed on screen)**
1. A frame is a pure function of `t`: no state kept between frames, no `Math.random`, any frame must render alone (the renderer uses two pages in turn).
2. Nothing visible may change per frame or switch on/off: ramp it (`smooth`), or use a slow wave (`noise1`, `fbm1`). At 30 or 60 fps a per-frame value reads as dropped frames.
3. Glow is additive: `MeshBasicMaterial`, `AdditiveBlending`, `depthWrite: false`, `toneMapped: false`, colour above 1 for bloom; keep any light it adds weak or the white face clips (QA `face_blown`).
4. The background stays darker than the characters; a known face is never redesigned (the owner 13/11).
5. Anything drawn above a head needs headroom: plan the framing (`ms_`, `two`) with the overlay, and end the overlay before the cut.
6. Text on a prop must be readable in the shot that shows it: check the still at full size, not the sheet.
**Episode-local additions (use these first; they need no edit in any shared file).** In the episode file: `poses: { ron: { myPose: { l: [...], r: [...] } } }` and `faces: { leo: { myFace: { ... } } }` are added to that character's tables; `props({ scene, set, cast, stage })` builds the episode's own objects (import `three` and the helpers of `core/util.js` in a file of your own, for example `episodes/<id>_props.js`) and returns `{ update(t, fx) }`, called every frame with the `fx` numbers of the acts on `'set'`. Promote a prop or a pose into a pack only when a second episode needs it.
GOAT Beef notes (13/11): the pub's neon and TV are steady by default (`setOpts.flicker: true` brings the on/off flicker back; never at 30 or 60 fps); `ctrTarget` is exported from `packs/goat/fans.js` for episode poses that put a hand on the bar object; the bar's nut bowl stays unless `setOpts.counter` is on; there is a 2 s limit on the tail after the last line, so a scoreboard that needs time must drop in BEFORE the last line.
**One writer per file.** `core/`, `tools/` and each pack are shared by every episode. When two agents build at the same time the driver gives each one a list of files it may edit and nobody edits outside it (13/11: an edit of `tools/voice.py` for GOAT Beef broke every Trà đá build for an hour). After any edit of `tools/voice.py` run `voice.py build episodes/ngay12.beats.json`; after any edit of `core/` or a pack run `python3 tools/regress.py`.
**Procedure**
1. Write a 10-16 s look test in `demo/` that shows only the new thing in the framings it will be used in (`demo/nnn_look.js` is the model).
2. `node tools/render.cjs stills demo/<test>.js <dir> <times>`; LOOK at the stills; tune; repeat. Three rounds is normal.
3. `node tools/qa.cjs` on the test, then `python3 tools/regress.py` (every approved episode still passes QA and still looks the same).
4. Add two or three lines to the "Added" section of this file: what it is called, how an episode asks for it.
5. Only then use it in the episode. If an engine edit is needed in the middle of a build, stop the build, do steps 1-4, resume.

## Added 15/11, SET SWAP: a 2-D board BEHIND the live 3-D cast (`kind: 'setswap'`, `core/player.js`, `core/stage.js`; look test `demo/setswap_look.js`, stills + sheet in `out/backdrop_look/`)
What it is: between `t0` and `t1` everything BEHIND the characters (wall, shelves, bunting, street, sign, floor) is replaced by a full-frame 2-D drawing; Tèo and Bíp stay exactly as they are (seated, lit by the same lights with their rim, shadows on the table, lips, acts, eye lines, ink outline). At `t0` the set cross-fades into the drawing over `fade` seconds, at `t1` the drawing fades back into the real set; the 3-D camera is untouched, so there is no cut either way. Captions and every other overlay still draw on top. (The older overlay `backdrop` is something else: blur + dim of the whole 3-D picture.)
```js
overlays: [{ kind: 'setswap', t0: 16.0, t1: 67.8, fade: 0.5,
             fn: (ctx, t, { ep, cast, a }) => { /* draw the board full-frame (1080 x 1920) onto ctx; a = how far the swap has faded in 0..1; the engine applies the fade itself, never use ctx.globalAlpha = a */ },
             keep: (obj, box, isDefault) => isDefault }]   // optional
```
- **Drawing**: `fn` runs on a private canvas BEFORE the 3-D cast is composited over it, every sub-frame (so `mblur` blurs the board's own camera moves). It must be a pure function of `t`. Put things that belong IN FRONT of the characters (a glow on Bíp's chest, text that overlaps them) in a normal `draw` overlay.
- **How it is rendered**: while a swap is active the set's top-level pieces that are not kept are hidden (lights are never hidden: the cast keeps its look), the scene is rendered on a TRANSPARENT background (`stage.setBackdrop(true)`: alpha = coverage, smooth MSAA edges, the final grade pre-multiplies by alpha, depth of field is switched off so nothing is blurred), and the page draws the board first and this picture over it (alpha composite). During the two fades the real set is drawn first, the board over it with the fade as alpha, the cast on top. `stage.setBackdrop(false)` and `premul = 0` give back the exact old opaque render: with no `setswap` in an episode every pixel is identical (`regress.py` PASS, inf dB, 15/11).
- **What `keep` holds** (default rule): a top-level child of `set.group` whose bounding box centre lies in the seating zone (x and z of the cast's seats +-0.65 m, z up to +1.0 m in front) and is lower than 1.3 m, and not wider than 2.2 m: for the stall that is the table with everything on it (glasses, plate, phone, tent cards) and the two stools. Everything else of the set goes. `keep(obj, box, isDefault)` overrides it per piece (return true to keep); lights and the cast are never hidden. With `overlays: false` (qa probes, raw stills) a swap is skipped, the picture is the real 3-D one.
- **Framing**: one steady two-shot is enough; give the heads room under the board: `{ cam: 'two', rig: { eye: 0.56, head: 0.15 } }` puts both heads at about y 880-1230 (above the caption band) and leaves the upper half of the frame to the board. A very slow `move: 'drift'` is fine.
- **Limits**: while a swap is active `aperture` is 0 (no depth of field), and the cast has no floor under it (the floor is part of the set and goes); `mblur` inside a swap composes every sub-frame separately (slower, only while the swap is fully faded in). Texts the board draws are not seen by `qa.cjs` (it records `draw` overlays only): declare them with a companion `{ kind: 'draw', t0, t1, reads: [...], fn: () => {} }`.
- Used by `episodes/t61.js` (the diagram board, `episodes/t61_props.js`). Checker for a board: `out/t61/diagram_look/border_check.cjs`.
