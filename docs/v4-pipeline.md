# pipeline.py: production gates (13/11)
`python3 tools/pipeline.py <command>` from `~/cine3d`. Config: `pipeline/channels.json`. State: files + `out/<id>/pipeline.json` (verdicts: who, when, hash of what was judged). Exit 0 ok, 1 refused, 2 usage. `--json` on status, next, can-post, list.

## Ask
`status <id>` one line per step + NEXT. `next <id>` who, model, effort, commands, proof, brief. `brief <id> <template>` prints `pipeline/briefs/<template>.md` with `{id} {channel} {channel_name} {root} {card} {treatment} {beats} {episode} {out} {mp4} {script_doc} {owner_fixed} {house_rules} {state_file}` filled (unknown ones stay, listed on stderr). `next` tries `<name>-<channel>.md`, then `<name>.md`.
A step is evaluated only if all earlier ones are DONE. Machine checks use the cache while input hashes are unchanged; `status <id> --run` re-runs the current step's checks (and the next's if it passes), never a later one. Crash or time-out (300 s) = ERROR, never PASS.

## Steps (done when)
1 card (fields below) / 2 treatment (headings About, Feelings, Cause chain, Tension curve, 0-3 s, 4-10 s, Last 15 s, Sound plan, each non-empty) / 3 script (`scriptlint --strict`; timing may be estimated, shown `(timing estimated; re-checked at the audio step)`) / 4 script_gate (PASS for the beats hash; goat also `facts` GO unless card `facts` is empty) / 5 voice (`voice.py need`: nothing missing) / 6 audio (build outputs newer than beats + `audiogate` + `scriptlint --strict` again with the real times) / 7 picture (`qa.cjs` + `clipcheck.cjs`) / 8 driver_review (OK for the episode hash; `out/<id>/cs*.jpg` must exist, newer than the episode) / 9 render (recorded mp4: 30 fps CFR, or 60 fps for renders made before 23/11/2026; newer than episode, `smooth.py`) / 10 episode_gate (PASS, mp4 hash) / 11 owner (OK + `--quote`) / 12 posted (>= 1 platform id) / 13 ledger (ledger.csv row of the video id with the channel's tag cells filled; WAITING until 72 h after posting).
A judged file changed after its verdict: `STALE (file changed since the verdict: re-ask only the changed points)`. **script_gate** hashes only what a reviewer judges: header `meta` + per SPOKEN beat `id who spk text say`, in order. Tension, gap, gain, sfx, music, duck, impact, tempo and pauses are NOT in it (sound edits after the gate keep it valid; text, speaker, `say`, order or meta make it STALE). Old whole-file records stay valid while the file is unchanged, else STALE with a message. Step 6 audio is cached on beats + episode `.js`; a cached SKIPPED check shows `DONE (1 check skipped: f; re-run with --run once the episode file exists)`.

## Record, force, post
`record <id> <step> <verdict> --by <who> [--note ..] [--quote ..] [--mp4 f] [--platform p --video-id v --at ISO] [--force "reason"]`. Verdict words, any case, the same for every step: pass / ok / done / go = positive, fail / fix / no / nogo = negative; it prints the stored word (script_gate PASS|FAIL, facts GO|NOGO, driver_review OK|FIX, render OK (`--mp4`, no negative), episode_gate PASS|FAIL, owner OK|NO (`--quote`), posted OK (`--platform --video-id`)). Refused because the lint cache is old: `inputs changed since the last lint: run pipeline.py status <id> --run, then record again`. Earlier steps not done: refused unless `--force "reason"`; forced records show forever in `status`, and `can-post` refuses them unless `--allow-forced` (the owner's call).
`can-post <id>`: exit 0 + `CAN POST` only when steps 1-11 are DONE, nothing stale. Run before posting.
`new <id> --channel X` writes only the missing card skeleton / pipeline.json, never overwrites. `adopt <id> --channel X`. `copy <src> <new> [--channel X]`: copies card, treatment, beats, `.js` and every `<src>.*` / `<src>_*` file; rewrites the exact id in `.js`/`.json`; takes come from the speaker|text index, takes only in `voice/<src>/` are copied; adopts. Refuses if the new id exists. `list [--channel X]`. No args or `--help`: usage.

## Card fields (`episodes/<id>.card.json`)
trada (required): `title`, `person`, `sum`, `recipient` (who a viewer would send it to), `first_frame`, `kind` = `standalone` | `series:<name>` | `special`. Optional: `thread`, `script_doc`, `owner_fixed`.
goat (required): `title`, `claim`, `side` = `ron` | `leo`, `comment_ron`, `comment_leo`, `facts` (list, `[]` for a fact-free script), `kind` = `fullbeef` | `quickie`. Optional: `script_doc`, `owner_fixed`.
`owner_fixed` (both): list of strings, points the owner decided that reviewers may not reopen. `{owner_fixed}` expands to `OWNER-FIXED, not open: a; b`, or to nothing (a line holding only the placeholder disappears).
Ledger tag cells after 72 h: trada `episode_id engine kind person sum opener`; goat `episode_id engine kind opener side_taken verdict_first`.

## Voice (`~/tdvai/.venv/bin/python tools/voice.py ...`)
`need <beats>`: lines with no take or a STALE take; per line chars + estimated credit (chars x 1.035, rounded up), total, also in `out/<id>/voice_need.json`. `find <SPK> <words>`: library takes whose text has all the words (case and accents ignored), exact text + path: reuse word for word. `takes.json` (`voice/<id>/`): the text each take was recorded from. A take whose text or `say` differs now prints `STALE TAKE l7: recorded "..." but the beat now says "..."`, counts as missing, and `build` stops (`--allow-stale` overrides). No record: one note; `stamp <beats> [ids]` vouches for the current text.
`record <beats> --ceiling <credits> [--max 5] [--yes] [--channel X]`: the missing lines in beat order, at most `--max`. Dry run unless `--yes`: speaker, voice id, text sent (`say` else `text`), chars, credit, batch + running total; refuses above the ceiling or a speaker with no id (`voices` map per channel in `pipeline/channels.json`, else the table in voice.py). `--yes`: one `eleven_v4` mp3 44.1 kHz request per line, key from `~/.config/cine3d/.env` (never printed), saves `voice/<id>/<beat id>.mp3`, logs text, chars, voice id, time; HTTP error = stop, no retry.
